# whohasme-site

The public website for **WhoHasMe**, served by GitHub Pages at [whohasme.app](https://whohasme.app).

| Page | Path |
|---|---|
| Home | `index.html` |
| Privacy policy | `privacy/index.html` → whohasme.app/privacy |
| Support | `support/index.html` → whohasme.app/support |

Plain static HTML: no analytics, cookies, fonts or third-party scripts. The email signup links out to a form hosted by the provider. The privacy policy's source of truth is the app repo's Privacy & Security doc; this copy is updated when it changes.
